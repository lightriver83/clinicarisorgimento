# clinicarisorgimento.it

Sito della Clinica Risorgimento (Forlì) — statico, Astro, zero cookie.

La strategia, le decisioni e i contenuti vivono nel repo privato `clinica-risorgimento-digitale`;
questo repo è solo il sorgente del sito pubblicato su GitHub Pages.

- `npm run dev` — sviluppo locale
- `npm run build` — build in `dist/`
- push su `main` → deploy automatico
